# CS 2430 Programming Project 2 - Sets and Multisets

**Student:** Sandro Demartin  
**Semester:** Summer 2026  
**Primary language:** Java 17

## Description
This project implements ordinary set operations with Boolean arrays and multiset operations with `LinkedHashMap<String, Integer>` objects. The main program runs three clearly labeled verification cases for each representation and prints the required results.

## Important Files
- `src/Project2App.java` - main program and representative test cases
- `src/OrdinarySetOperations.java` - ordinary set algorithms and formatting
- `src/MultisetOperations.java` - multiset algorithms and formatting
- `examples/sample_output.txt` - output produced by the program
- `screencast_script.txt` - suggested narration and demonstration sequence

## Build and Run from a Terminal
From inside the `project2` folder:

```bash
javac -d out src/*.java
java -cp out Project2App
```

## Expected Environment
- Java Development Kit (JDK) 17 or newer
- No external libraries are required
